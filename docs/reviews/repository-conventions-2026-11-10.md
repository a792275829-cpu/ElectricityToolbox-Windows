# 仓库约定扫描与整改（2026-11-10）

依据根目录 AGENTS.md 与用户确认的 A 范围，处理代码、目录、依赖、CI、文档及测试偏差。
开始时处于 main，工作区干净；初始扫描包含 549 个 Git 跟踪文件、357 个 Python/PYW 文件。
历史 macOS 代码与启动脚本保留原位；不修改业务日期、字段、模板、输出命名或覆盖口径。

## 约定与结果

| 编号 | 约定／发现 | 整改结果 |
| --- | --- | --- |
| 1 | 工作簿跨进程锁测试超时 | 发现成功获取锁后的测试子进程只调用 `__enter__()`，未退出上下文；改用完整 `with`。冲突仍被拒绝，退出后再次获取成功，无旁置锁文件。不修改业务锁算法。 |
| 2 | Windows 单平台、构建不自动发布 | 原 macOS CI／发布入口改为 Windows reusable workflow 的兼容转发；删除标签发布触发器和 Release 写权限，只有人工下载构建附件后发布。 |
| 3 | Python 精确版本与 x64 | 初始化及源码 smoke 从 `.python-version` 读取并核对精确版本、指针宽度及 Tk；不再接受任意 3.11+。旧环境不符时明确停止，不自动覆盖。 |
| 4 | 构建前版本与更新说明完整 | Windows 构建在重建目录前调用 `version.py check --require-notes`；CI 同样检查，可额外核对传入标签。 |
| 5 | 全量测试覆盖所有目录 | 纳入市场日报、生产经营汇报、交易分析、电量汇总、风力预测的 23 个原有 Python 模块。 |
| 6 | 显式分组必须执行 | `--group section` 等显式分组选取完整组；空集合返回失败，不再以零用例冒充验证成功。 |
| 7 | 模块独立进程和超时 | 桌面组从整目录一次执行改为逐模块执行，用户指定的超时不再被强制提高。 |
| 8 | Node 可选、测试不遗漏 | 纳入 5 个独立 Node 测试文件；full 缺少 Node 明确跳过，显式 node 组缺少 Node 报错；CI 安装上传子工具依赖后执行统一 full。初始化 npm 失败单独提示，不阻断已完成的 Python 环境。 |
| 9 | Python 依赖唯一版本来源 | WPS requirements 改为转引 Windows 统一清单，不再维护独立宽松版本。 |
| 10 | 系统操作集中适配 | WPS 的 taskkill 调用移入 `toolbox_platform.terminate_windows_process`；保留调用前归属检查、先关闭可见窗口再强制关闭的顺序。 |
| 11 | 当前文档只指导 Windows | 更新主 README、桌面说明、架构、目录、500kV、原生后端和打包说明；测试示例统一入口，修正旧清空目录和评审路径说明。 |
| 12 | 文档归档与用户更新说明 | 0.1.35／0.1.36 原始详细记录完整归档到 `docs/releases/vX.Y.Z.md`；早期 Windows 验证移入 releases，原入口保留重定向；修正共享模块数量及索引。已发布资产不修改，其他历史条目不补造新增功能。 |
| 13 | 风格、命名与改动边界 | 仅整理实际修改代码的导入／缩进；保留原目录、共享模块名与文件换行风格。PowerShell 入口保持 UTF-8 BOM 以兼容 Windows PowerShell 5.1。 |
| 14 | 保留失败现场 | `--keep-temp` 保留各模块子目录；补充回归检查，确保诊断文件仍可读取。 |

新纳入的测试另发现并修复两处测试环境偏差：交易原生对照须传入生产适配器已有的 Python 版本求和选项；字体测试不再修改全局 `sys.platform`，并在用例间清空字体缓存。
未放宽精度断言或改动业务计算。字体测试仍检查中文字符、字号、粗细、图片尺寸与可移植路径。

## 验证

- 整改前：Python/PYW 语法通过；依赖与版本检查通过；fast 的 39 个工具箱模块通过，桌面 268 项中 1 项锁测试报错、33 项跳过，单独复跑仍失败。
- 修复后：锁与 Windows 平台模块通过；新纳入的交易／字体测试、WPS 关闭顺序与兼容测试通过。
- 统一入口为每个模块设置独立数据根目录，避免读取源码工作区的真实配置与登录态，并向所有分组提供工具箱导入路径。此前全量运行的 WPS 登录态 Mock 失败和 500kV 导入失败由此消除。
- 测试入口新增回归覆盖数据隔离、目录可达性、模块隔离、显式分组、空集合、去重、保留诊断文件、超时与缺少 Node；初始化真实版本门禁通过正确版本／拒绝错误补丁版本两项检查。
- PowerShell 语法解析、真实 PowerShell 5.1 源码 smoke（所有运行依赖导入）、pip check、构建归档 DryRun（未修改文件）、v0.1.36 版本及更新说明校验通过。
- actionlint 1.7.12 校验全部工作流通过；工具仅保存于 Git 忽略的 dist 验证目录。
- 第一次 full 为 150/153 个模块通过，3 个失败均已单独复跑通过。
- 最终隔离环境、与 CI 一致的严格 Rust 变量下执行 full：149/154 个模块通过（563.4 秒）。5 个失败分别为电价预测路径、功率收益登录目录、工具箱跨工具登录目录、无编译后端的源码拓扑载荷夹具、汇报登录目录断言；均为测试环境假设，已按源码／隔离数据路径或夹具真实后端能力修正。
- 最后对上述 5 个模块集中复跑：5/5 通过（56.4 秒）。最终代码覆盖全部 154 个模块；没有将首次全量失败表述为一次性全量全绿，也未在测试专用修正后重复整轮。
- `--keep-temp` 实际运行并回读模块及数据子目录成功；未发现本轮锁测试遗留的 Python 子进程。全部 359 个 Python/PYW 文件语法解析、当前文档链接和 `git diff --check` 通过。
- 0.1.35、0.1.36 归档章节与整改前 Git 中的原文逐字核对一致。

## 交付边界

本轮不提高应用版本、不构建安装包、不创建标签或 Release、不提交推送，等待用户审阅后的选择。
没有使用生产账号执行登录、上传或真实业务工作簿写入；未执行新安装包与增量补丁还原验收。
已有 macOS 历史测试按自身平台条件跳过，不增加 macOS 支持承诺。
