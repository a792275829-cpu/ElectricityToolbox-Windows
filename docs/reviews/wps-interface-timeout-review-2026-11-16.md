# WPS 分层超时调整（2026-11-16）

沿用 [前次无限等待检查](wps-write-timeout-review-2026-11-15.md) 的不自动重写及退出保护，按用户确认的规则调整：

- 单次 SDK 接口等待超过 20 秒仍未返回即报超时；接口正常返回后，下一次调用重新计时。
- 一批目标表格的写入、保存和回读保留 180 秒总上限，不因接口持续返回而重置。
- 排队仍为 30 秒；超过时提示原任务仍在运行、本次操作尚未提交，不释放原任务占用的锁，也不取消原任务。
- 目标表格的合并状态、已有值、公式、保存和回读均走单接口期限；来源区域与工作表信息读取同样覆盖。
- 单接口超时与总超时均标记操作过期，迟到的接口返回不能恢复剩余写入；写入结果提示待核对，不自动重试。
