# Windows v0.1.45 发行验收记录

用户可见变化以根目录 `CHANGELOG.md` 为唯一来源；本文件记录本轮的验收范围、环境与结果，
实现细节和验证证据在此留档，不改写已发布版本的历史记录。

## 范围

- 源码：`main` 上 v0.1.44 之后的 5 个业务文件——`上网电量抓取/export_online_energy.py`（厂站电量倍率）、`南方分公司电力市场日报/gd_power_report/company_clearing_xlsx.py` 与 `pipeline.py`（全省日前均价环比）、`toolbox_wps_config.py` 与 `wps自动/wps_excel_to_kdocs_gui.py`（配置导入导出省略文档位置）。
- 随包默认配置：`wps自动/wps_excel_to_kdocs_config.defaults.json` 更新为 3 项共 39 个写入区域，默认仅填空白单元格，`overwrite=false`，来源/目标链接与本地路径全部留空。
- 测试：`desktop/tests/python/test_wps_packaging.py`、`电力工具箱/tests/test_toolbox.py`、`test_wps_url_titles.py`、`test_online_energy_output.py` 调整口径并补回归；新增 `电力工具箱/tests/test_market_report_price_comparison.py`（7 例）。
- 文档：新增评审记录 `docs/reviews/code-review-2026-11-18.md`；`README.md` 的默认配置说明同步改写。
- 用户可见变化：`CHANGELOG.md` 的 0.1.45 条目共 3 条，`[Unreleased]` 草稿已整理并移除。
- 发行产物：`ElectricityToolbox_0.1.45_windows_x64_setup.exe`、同名 `.sha256`、`updates-0.1.45/` 内的增量补丁与 `windows-update-manifest.json` 及其摘要、`source-0.1.45.json`。

## 环境

- Windows 10 / 11 x64；Windows PowerShell 用于构建入口，Git Bash 用于只读检查。
- `.python-version` 为 3.11.15；独立 CPython `.toolbox/standalone-python` 与测试用 `.venv/Scripts/python.exe` 均为 3.11.15。
- Rust / cargo 位于 `%USERPROFILE%\.cargo\bin`（未加入 Git Bash 的 PATH，测试用绝对路径调用）。
- 旧版基线：本地留存的 `ElectricityToolbox_0.1.44_windows_x64_setup.exe`，用于覆盖升级与增量补丁还原。
- 复用 v0.1.44 构建后的 release 缓存；测试使用统一入口的隔离数据目录；不执行生产账号登录、真实上传或业务工作簿写入。

## 结果与证据（发行前检查）

- `version.py check --tag v0.1.45 --require-notes` 输出 `v0.1.45`，package.json、package-lock.json、tauri.conf.json、Cargo.toml、Cargo.lock 五处一致。`version.py set` 仍会在首个 `## ` 前插入正式条目并保留 `[Unreleased]` 草稿，已按约定手工移除草稿段。
- `git -c core.whitespace=cr-at-eol diff --check` 通过；待提交 23 个文件（+745 / −269），均为源码、测试、文档与版本元数据，无凭据、登录态、业务工作簿或构建产物。
- `tools/run_tests.py full --strict`：**151 / 155 通过、跳过 0，用时 673.9 秒**。失败的 4 个模块 `desktop:test_windows_delta`、`test_windows_update`、`test_windows_update_build`、`test_windows_update_helper` 均为会话注入的批量删除守卫在 `apply_patch` 删除文件时以 `SystemExit: 1` 中断（`_check_bulk_delete_guard` → `_exit_bulk_guard_control`），不是断言失败，与本轮改动无关。
- 未绕过守卫：4 个模块**逐模块单独调用**复跑（每次工具调用重置计数），分别 **15/15、23/23、8/8、18/18** 全部通过。加上全量中通过的 151 个模块，155 个模块均已通过。
- 本轮相关模块在全量中的结果：新增 `toolbox:test_market_report_price_comparison` **7/7**、`toolbox:test_wps_cold_start` 2/2、`toolbox:test_wps_layout` 3/3、`toolbox:test_online_energy_output` 31/31、`test_toolbox` 92/92、`test_wps_url_titles` 10/10、`desktop:test_wps_packaging` 4/4。
- 首轮全量（`dist/full-test-0.1.45.log`）暴露 2 个真实失效：`test_wps_cold_start` 仍按 34 个区域断言、`test_wps_layout` 仍假定默认覆盖非空单元格。已按新默认（39 个区域、`overwrite=false`）改口径并复跑通过；重跑后的完整记录为 `dist/full-test-0.1.45b.log`。
- `start_source_test.ps1 -Smoke` 输出 `TOOLBOX_DEPS=OK`、`TOOLBOX_SMOKE=OK`。
- Rust：`cargo test --manifest-path native/price-xlsx/Cargo.toml --locked` **13/13 通过**；`cargo test --manifest-path desktop/src-tauri/Cargo.toml --locked` **3/3 通过**。
- 代码审阅补正（见 `docs/reviews/code-review-2026-11-18.md` 的「0.1.45 修复记录」）：
  - 均价环比归属收紧为「比较短语自成一分句 + 取最靠前一条」，`全省日前均价350元/兆瓦时，机组报价环比上涨20元/兆瓦时` 不再算出 +20；同句先写均价比较时也不再按固定词序取错。
  - 备用简析在使用前比对工作表日期，日期全部早于目标日时按缺值处理，避免把上一日快报的均价当成本日基准。
