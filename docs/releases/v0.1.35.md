# Windows v0.1.35 历史验证记录

以下内容从整改前的 CHANGELOG 原样归档，用于追溯当时的实现、验证与限制；不代表本轮重新执行，也不作为当前操作说明。
已发布安装包和 Release 内容不作修改。当前用户可见变更摘要仍以根目录 CHANGELOG 为唯一来源。

## [0.1.35] - 2026-11-09

- 加固 Windows 自动更新后的重启：安装成功后会校验新版本进程是否真的存活，启动即退出时自动重试并从系统外壳再次拉起；仍失败则恢复旧程序，并在下次启动提示具体原因
- 验证：新增两条重启判定单元测试（立即退出判失败、正常启动判成功）通过；安装助手端到端用例因本机安全策略拦截 reg.exe 未能运行
- 修复更新 0.1.34 后提示「内置 Python 不完整，请重新安装完整发行版」：安装助手替换程序后校验内置 Python/Node、任务服务与业务桥接文件，缺失或被替换时自动恢复旧程序并报出具体文件；此前 Tauri 宿主在后端启动失败时仍存活，仅凭重启进程存活会把坏安装判为成功并删除旧版备份
- 验证：新增 3 条运行时校验 Rust 单测与 1 条缺内置 Python 回滚端到端用例；Rust 测试子集 10/10、Windows 增量与更新器 Python 单测 35/35 通过；注册表相关 2 条单测与端到端用例受本机 reg.exe 安全策略拦截未验证
- 打包入口 build.ps1 在 NSIS 前强制校验 payload：版本须与 desktop/package.json 一致、内置 toolbox-service.exe 须与清单哈希一致且不早于 Rust 源码，避免跳过 prepare_payload.py 把旧更新逻辑打进新版本；验证：新增 6 条 payload 新鲜度单测通过，当前工作副本的 0.1.34 payload 已被按预期拦截，build.ps1 语法与 version.py check 通过
- 修复逐模块审查确认的六项问题：500kV 分析保留输入及历史结果；WPS 在来源公式缺少计算结果时停止写入；现货价格拒绝同场站同日期的重复完整记录；交易分析各 GUI/CLI/服务入口统一预检同名报告冲突；私有批量上传拒绝异常响应结构；Rust 服务保留登录错误分类、原始业务退出码及人工登录提示，并对错误元数据脱敏。
- 验证：117 项针对性 Python 回归、15 项 Node 响应协议测试及 20 项 Rust 单测通过；源码启动自检 `TOOLBOX_SMOKE=OK`。使用临时工作簿回读核对值、空白与格式，并验证输入文件字节保持不变；未使用生产系统执行上传或在线写入。
- 修复南方分公司电力市场日报加入 D 日全天出清明细后报告日期识别变慢：日期识别原本用 `read_only=False` 展开整本工作簿（含整日明细的全部单元格、公式与合并区），只为了读「新快报」A6/A2/A7。现改为独立调用走只读流式加载、调用方已持有完整工作簿时直接复用；无「新快报」的旧版快报仍走原完整解析，A6→A2→A7→文件名的日期口径、工作表选择规则与错误文案均不变。
- 验证：0.45–0.9 MB、约 18 万单元格的模拟工作簿中全量加载耗时 0.78–1.5 s，识别由 1.5 s 降至 7–10 ms（经工具箱页面入口首次含模块加载 22–96 ms）；日报模块 76 项、工具箱相关 34 项回归通过，新增 6 项只读／复用／旧格式回退测试；源码启动自检 `TOOLBOX_SMOKE=OK`。
- 排查并修复同类「只为读几个单元格而展开整本工作簿」的取数路径：D-2 日出清情况取数改为一次性物化只读值快照，并在同一次生成内复用；按日期逐个试读日前对比候选时先以只读句柄核对日期，仅在命中后才完整展开，避免为每个落选文件付整日明细的解析成本。D 日前对比表校验与日期识别保留完整加载，因其句柄会被流水线解析直接复用，改只读反而多一次完整加载。
- 验证：0.47 MB、含 9.6 万单元格整日明细的出清工作簿，取数 784 ms → 444 ms（1.8×），回读各行取值与现货偏差数据逐项一致且重复调用一致；日报模块 76 项、汇报工具 82 项、工具箱相关 85 项回归通过；源码启动自检 `TOOLBOX_SMOKE=OK`。
- 修复早报「上网电量＋日前均价」段在 D-1 上网电量未出数时整段冻结：日均价与电量同属一段，电量取不到时原逻辑保留模板原文，导致「快报  (日前)」已有的均价数停在上一份报告的旧值（如 160 厘/524 厘）却看不出未同步。现拆开处理——电量句改写为「上网电量待补充（当日尚未出数）」并单独标红，日前均价仍按当日「快报  (日前)」G/H 列更新为黑字。
- 验证：新增 2 项用例（电量缺失时均价仍更新、段落仅电量句标红）通过；汇报工具 84 项回归全绿；用真实模板与《出清情况（分公司2026.11.9）》复现该分支，回读段落为红字「11月9日分公司上网电量待补充…」＋黑字「分公司日前均价45厘…汕头410厘、海门-50厘、东莞434厘…」，仿宋10pt格式保留；源码启动自检 `TOOLBOX_SMOKE=OK`。
- 针对 Windows SmartScreen／安全中心拦截内置运行环境：更新器在下载文件与更新助手通过 SHA-256 校验后清除 Zone.Identifier，助手无输出即退出时明确提示安全软件拦截；启动故障窗口列出缺失路径和「保护历史还原／排除目录／重装完整包」步骤；新增 repair_smartscreen.ps1 恢复工具与安装说明
- 验证：新增 2 条 MOTW 清除单测随更新器 22/22 通过，payload 新鲜度 6/6、更新 UI 21/21 通过；Tauri 宿主 cargo check --release 通过；repair_smartscreen.ps1 语法解析与对真实 payload 实跑通过（正确读出 0.1.34 版本并列出缺失文件）
