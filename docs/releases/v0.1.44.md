# Windows v0.1.44 发行验收记录

用户可见变化以根目录 `CHANGELOG.md` 为唯一来源；本文件记录本轮的验收范围、环境与结果，
实现细节和验证证据在此留档，不改写已发布版本的历史记录。

## 范围

- 源码：`main` 上 v0.1.43 之后的 2 个业务文件——`集团每日上传/upload_daily_report.py`（省内数据固定使用内置模板、日报状态按日期/类型/省份筛选唯一记录）与 `每日生产经营情况汇报自动生成工具/scripts/generate_red_marked_report.py`（天气主源失败切换中国天气网广州预报，8 秒超时、三天日期与温度校验）。
- 工具箱界面：`电力工具箱/toolbox/pages.py` 与 `toolbox/service_catalog.py` 的集团上传页改为只选能销文件，界面提示与文件对话框同步。
- 测试：3 个工具箱测试模块与 1 个早报测试模块调整口径并补回归（状态多行筛选、重复匹配仍报错、内置模板忽略同目录历史文件、天气切源/缺日/缺温度/跨年/双源全失败）。
- 文档：新增 2 份评审记录（`docs/reviews/group-upload-2026-11-17.md`、`docs/reviews/weather-fallback-2026-11-17.md`），`README.md` 与 `集团每日上传/templates/README.md` 的选择顺序说明同步改写。
- 用户可见变化：`CHANGELOG.md` 的 0.1.44 条目共 2 条，`[Unreleased]` 草稿已整理并移除。
- 发行产物：`ElectricityToolbox_0.1.44_windows_x64_setup.exe`、同名 `.sha256`、`updates-0.1.44/` 内的增量补丁与 `windows-update-manifest.json` 及其摘要、`source-0.1.44.json`。

## 环境

- Windows 10 / 11 x64；Windows PowerShell 用于构建入口，Git Bash 用于只读检查。
- `.python-version` 为 3.11.15；独立 CPython `.toolbox/standalone-python` 与测试用 `.venv/Scripts/python.exe` 均为 3.11.15。
- Rust / cargo 位于 `%USERPROFILE%\.cargo\bin`（未加入 Git Bash 的 PATH，测试用绝对路径调用）。
- 旧版基线：本地留存的 `ElectricityToolbox_0.1.43_windows_x64_setup.exe`，用于覆盖升级与增量补丁还原。
- 复用 v0.1.43 构建后的 release 缓存；测试使用统一入口的隔离数据目录；不执行生产账号登录、真实上传或业务工作簿写入。

## 结果与证据（发行前检查）

- `version.py check --tag v0.1.44 --require-notes` 输出 `v0.1.44`，五处版本元数据一致。`version.py set` 仍会在首个 `## ` 前插入正式条目并保留 `[Unreleased]` 草稿，已按约定手工移除草稿段，历史 40 个版本条目原样保留。
- `git -c core.whitespace=cr-at-eol diff --check` 通过；待提交文件均为源码、测试、文档与版本元数据，无凭据、登录态、业务工作簿或构建产物。
- `tools/run_tests.py full --strict`：**150 / 154 通过、跳过 0，用时 898.3 秒**。失败 4 个模块 `desktop:test_windows_delta`、`test_windows_update`、`test_windows_update_build`、`test_windows_update_helper` 均为会话注入的批量删除守卫在 `apply_patch` 删除文件时以 `SystemExit: 1` 中断（`_check_bulk_delete_guard` → `_exit_bulk_guard_control`），不是断言失败，也与本轮改动无关（本轮未触碰 `desktop/python/windows_delta.py` 与更新工具链）。
- 未绕过守卫：本轮以 `--group desktop` 新进程复跑仍在该工具调用内累计到阈值（25 / 29），改为**逐模块单独调用**（每次工具调用重置计数）复跑，4 个模块分别 **15/15、23/23、8/8、18/18** 全部通过。加上全量中通过的 150 个模块，154 个模块均已通过。
- 本轮相关模块在全量中的结果：`toolbox:test_group_upload_safety` 6/6、`test_group_upload_template` 8/8、`test_group_upload_shutdown` 6/6、`test_toolbox` 92/92、`report:test_report_text` 19/19。
- `start_source_test.ps1 -Smoke` 输出 `TOOLBOX_DEPS=OK`、`TOOLBOX_SMOKE=OK`。
- Rust：`cargo test --manifest-path native/price-xlsx/Cargo.toml --locked` **13/13 通过**；`cargo test --manifest-path desktop/src-tauri/Cargo.toml --locked` **3/3 通过**。
- 待提交规模：20 个文件（+304 / −119），其中 15 个为源码／测试／版本元数据修改，2 份新增评审记录，另加本发行记录与文档索引。
- 代码审阅补正：`集团每日上传/upload_daily_report.py` 删除自动挑模板逻辑后 `timedelta` 已无引用，随本轮去掉该导入，行为不变。
