# Windows v0.1.47 发行验收记录

用户可见变化以根目录 `CHANGELOG.md` 为唯一来源；本文件记录本轮的验收范围、环境与结果，
实现细节和验证证据在此留档，不改写已发布版本的历史记录。

## 范围

- 早报机组启停：`每日生产经营情况汇报自动生成工具/scripts/generate_red_marked_report.py` 新增
  `_day_ahead_unit_transitions`，按「汕头」「海门」工作表的机组号与「日前电量」表头读取 0:00 至 23:00 的
  24 点电量；24 点全部有效且正值与零之间只切换一次时，以「运行转备用」/「备用转运行」覆盖「基础信息」的
  机组状态，东莞与清远继续沿用基础信息。`fill_startup_status` 对含转换的段落不再简写为「与前一日运行方式一致」。
- 日报价格口径：`compare_strategy_day_ahead_price` 用报告日与前一日「快报（日前）」A41 的全省日前均价
  重算现货交易策略段环比（`Decimal` 两位、`ROUND_HALF_UP`，含「环比持平」）；日清分「日前市场」直接引用
  清分日 A41 原文的全省日前出清均价及环比，删除原「全省节点均价（日更）」96 点平均与 `find_first_column_row`
  旁路；实时均价仍按 `快报` 实时简析替换。
- WPS 写入：`wps自动/wps_excel_to_kdocs_gui.py` 删除逐区域 `range.MergeCells` 等待及其返回字段，
  批量写入不再因未使用的合并状态查询触发接口超时。
- 测试：`test_unit_status`（新增 `DayAheadUnitStatusTests` 与实际曲线样本）、`test_report_text`
  （改为各自快报取数）、`test_wps_api_recovery`（对齐去掉 `mergeCells` 的脚本）。
- 诊断留档：`docs/reviews/report-unit-status-2026-11-20.md`。
- 发行产物：`ElectricityToolbox_0.1.47_windows_x64_setup.exe`、同名 `.sha256`、`updates-0.1.47/`
  内的增量补丁与 `windows-update-manifest.json` 及其摘要、`source-0.1.47.json`。

## 验证边界

- 主程序仍为未签名构建（与既有发行一致，项目未做代码签名）；静默安装目录内无 `state/installed.json`，
  改以各安装目录 `payload/manifest.json` 回读版本。
- 机组启停识别只在临时样本（实际出清表的只读副本）上验证汕头停机、海门开机的转换输出，
  未用当日生产工作簿做端到端出报告；识别条件为 24 点全部有效且 0/正值只切换一次，缺失或不满足时
  自动回退基础信息状态。
- 日报均价重算依赖报告日与前一日「快报（日前）」A41 各只有一个全省日前均价；不满足时保留原文并记录错误，
  不中断整份早报。
- WPS 写入的验证口径为单元级恢复用例（26/26）与脚本内不再等待 `MergeCells`，**未**在真实 WPS 会话中
  跑大批量写入回归。
- `version.py set` 在 Windows 上用默认文本模式写文件，会把原本 LF 的 `CHANGELOG.md` 整体转成 CRLF
  （本轮首提交因此产生 417 行噪音，已还原为 LF 后修正）；`package.json`／`Cargo.toml` 本身为 CRLF 未受影响。
  该隐患尚未修复，下次发行前需给写入路径固定换行符。
