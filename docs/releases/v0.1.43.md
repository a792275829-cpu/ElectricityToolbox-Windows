- Windows 10 / 11 x64；Windows PowerShell 用于构建入口，Git Bash 用于只读检查。
- `.python-version` 为 3.11.15；独立 CPython `.toolbox/standalone-python` 与测试用 `.venv/Scripts/python.exe` 均为 3.11.15。
- Rust / cargo 位于 `%USERPROFILE%\.cargo\bin`（未加入 Git Bash 的 PATH，测试用绝对路径调用）。
- 旧版基线：本地留存的 `ElectricityToolbox_0.1.42_windows_x64_setup.exe`，用于覆盖升级与增量补丁还原。
- 复用 v0.1.42 构建后的 release 缓存；测试使用统一入口的隔离数据目录；不执行生产账号登录、真实上传或业务工作簿写入。

- `version.py check --tag v0.1.43 --require-notes` 输出 `v0.1.43`，五处版本元数据一致。`version.py set` 按仓库既有行为在首个 `## ` 前插入正式条目、保留 `[Unreleased]` 草稿，已按约定手工移除草稿段，历史 39 个版本条目原样保留。
- `git -c core.whitespace=cr-at-eol diff --check` 通过；待提交文件均为源码、测试、文档与版本元数据，无凭据、登录态、业务工作簿或构建产物。
- `tools/run_tests.py full --strict`：**150 / 154 通过、跳过 0，用时 561.7 秒**。失败 4 个模块 `desktop:test_windows_delta`、`test_windows_update`、`test_windows_update_build`、`test_windows_update_helper` 均为会话注入的批量删除守卫在同一工具调用内累计 50 次删除后以 `SystemExit: 1` 中断（`_check_bulk_delete_guard` → `_exit_bulk_guard_control`），不是断言失败，也不来自本轮改动。
- 未绕过守卫：改用 `--group desktop` 在独立进程（守卫计数重置）复跑，**29 / 29 模块通过、166.3 秒、跳过 0**，含上述 4 个模块（分别 15、23、8、18 个用例）；单独复跑这 4 个模块亦为 15/15、23/23、8/8、18/18。
- 全量运行期间 `report` 组真实结果：`test_report_text` 14/14、`test_daily_clearing_fill` 17/17、`test_online_energy` 9/9、`test_workbook_dates` 8/8，覆盖本轮早报修改。
- `start_source_test.ps1 -Smoke` 输出 `TOOLBOX_SMOKE=OK`、`TOOLBOX_DEPS=OK`。
- Rust：`cargo test --manifest-path native/price-xlsx/Cargo.toml --locked` **13/13 通过**；`cargo test --manifest-path desktop/src-tauri/Cargo.toml --locked` **3/3 通过**。
