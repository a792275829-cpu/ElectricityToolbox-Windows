# Windows v0.1.41 发行验收记录

用户可见变化以根目录 `CHANGELOG.md` 为唯一来源；本文件记录本轮的验收范围、环境与结果，
实现细节和验证证据在此留档，不改写已发布版本的历史记录。

## 范围

- 源码：`main` 上 v0.1.40 之后的 11 个修改文件与 3 个新增文件：早报 A 类及地方电出力增减口径、日清分表无效均价与缺失收益的无效状态保留、`快报(日前)` A41 原文整句采用与抓数不再依赖市场行情开机接口、交易系统信息更新对历史模板的识别、节点电价汇总（新增根目录共享模块 `toolbox_node_prices.py`，新增「海风汇总」与「全省汇总」），以及针对性测试；另有本轮的版本元数据、更新日志与发行记录改动。
- 用户可见变化：`CHANGELOG.md` 的 0.1.41 条目共 8 条，草稿 `[Unreleased]` 已整理完毕、无未完成条目残留。
- 发行产物：`ElectricityToolbox_0.1.41_windows_x64_setup.exe`、同名 `.sha256`、`updates-0.1.41/` 内的增量补丁与 `windows-update-manifest.json` 及其摘要、`source-0.1.41.json`。

## 环境

- Windows 10 / 11 x64；Windows PowerShell 5.1 用于构建入口，Git Bash 用于只读检查。
- `.python-version` 为 3.11.15；独立 CPython `.toolbox/standalone-python` 与测试用 `.venv/Scripts/python.exe` 均为 3.11.15，三者一致。
- Rust / cargo 1.99.1、Node 22.22.2、NSIS makensis。
- 旧版基线：本地留存的 `ElectricityToolbox_0.1.38_windows_x64_setup.exe`、`ElectricityToolbox_0.1.39_windows_x64_setup.exe` 与 `ElectricityToolbox_0.1.40_windows_x64_setup.exe`。
- 复用 v0.1.40 构建后的 release 缓存（已确认无旧解压路径残留），不重复清理；测试使用统一入口的隔离数据目录；不执行生产账号登录、真实上传或业务工作簿写入。
- 新增根目录模块 `toolbox_node_prices.py` 满足载荷 `runtime_source` 谓词的 `toolbox_*.py` 规则，须在提交后进入正式构建载荷，并在安装版验证导入。

## 结果与证据（发行前检查）

- `version.py check --tag v0.1.41 --require-notes` 输出 `v0.1.41`；package.json、tauri.conf.json、package-lock.json、Cargo.toml、Cargo.lock 五处版本一致。发布说明由 `version.py check --release-notes` 导出到 `dist/v0.1.41-release-notes.md`（3,335 字节），内容为本版 8 条变更与通用安装说明；`[Unreleased]` 的 8 条草稿全部完成并整理为 0.1.41 正式条目，无重复维护、无未完成条目残留。
- `git -c core.whitespace=cr-at-eol diff --check` 通过（仓库元数据文件本身为 CRLF）。待提交 22 个文件均为源码、测试、文档与版本元数据，无凭据、登录态、业务工作簿或构建产物。新增的 2 份测试均显式声明 `TOOLBOX_TEST_TAGS = ()`；新增根目录模块 `toolbox_node_prices.py` 符合载荷 `runtime_source` 的 `toolbox_*.py` 规则，被 `summarize_511_excel.py` 与 `review_classification.py` 共同导入，须在提交后进入载荷并于安装版验证导入。
- `tools/run_tests.py full --strict`：**157 个用例中 153 个通过、跳过 0，用时 557.2 秒**，失败 4 个模块（`desktop:test_windows_delta`、`test_windows_update`、`test_windows_update_build`、`test_windows_update_helper`）。这是首次全量运行的真实结果，不表述为一次性全绿。4 个模块的 traceback 全部指向会话注入的 `sitecustomize.py::_check_bulk_delete_guard`，拦截临时目录清理、`path.unlink()` 与 `shutil.rmtree()`；未发现产品代码回归。
- 对这 4 个模块用统一入口 `--module` 集中复跑（无会话注入环境）：**4/4 通过、跳过 0，用时 56.7 秒**。未因复跑通过而改写首次全量结果，也未重复整轮。
- Rust：`cargo test --manifest-path native/price-xlsx/Cargo.toml --locked` **13/13 通过**；`cargo test --manifest-path desktop/src-tauri/Cargo.toml --locked` **2/2 通过**（debug 编译 1 分 23 秒）。复用 0.1.40 的缓存，未出现 build script 读取插件权限文件失败。
- `start_source_test.ps1 -Smoke` 输出 `TOOLBOX_SMOKE=OK`、`TOOLBOX_DEPS=OK`。
- GitHub 发布通道：`api.github.com` 凭据可用，仓库有 push 权限，最新公开 Release 为 `v0.1.40`（draft=false、7 个附件），v0.1.41 尚未存在。
